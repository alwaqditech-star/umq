# Brand Evolution — UMQ

## Goal

Elevate visual quality to enterprise SaaS level (Stripe, Vercel, Linear) while **keeping core UMQ colors**.

## Changes

1. **Mesh gradients** replace flat backgrounds (`MeshBackground`).
2. **Softer borders** — reduced opacity, gradient frames on CTAs.
3. **Depth** — layered shadows (`card-elevated`, `surface-premium`).
4. **Motion** — scroll reveals, hover lift, mobile menu transitions.
5. **Typography** — gradient headlines, kicker pills for sections.

## Not changed

- Logo wordmark treatment (`text-gradient` on brand name)
- Primary CTA color (`#0F244D` / accent hover)
- RTL/LTR locale structure
